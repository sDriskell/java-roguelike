METHOD ARGUMENT NAMES:
	-Should start with 'arg' with few exceptions
	-Single character arguments should not start with 'arg' -- too bloaty
	-booleans be in form of a question (isLocked, hasKey)

ABBREVIATIONS:
	-itm	item
	-col	color
	-h		height
	-w		width
	-msg	message
	-term	terminal
	-plyr	player
	-tgt	target
	-pos	position
	-atk	attack
	-act	actor
	-dmg	damage
	-atkr	attacker
	-def	defense
